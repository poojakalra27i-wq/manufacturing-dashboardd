# Line Productivity & Downtime Analysis Dashboard

## Project Overview

This project focuses on analysing production line productivity and downtime using Power BI. The dashboard provides insights into production performance, downtime patterns, product-wise performance, and potential operational inefficiencies.

The objective is to help identify areas for improvement, support data-driven decision-making, and improve overall manufacturing efficiency.

## Tools & Technologies

- **Power BI:** Dashboard development and data visualization
- **SQL:** Data querying and analysis
- **Data Analytics:** KPI monitoring and performance analysis

## Key Features

- Production performance monitoring
- Downtime analysis and trend identification
- Product-wise and flavour-wise comparisons
- Operator-related performance analysis
- Analysis of downtime categories and possible causes
- Interactive filters for exploring different dimensions of production data

## Key Insights

1. **Downtime Monitoring:** Analysing downtime trends helps identify periods of reduced operational efficiency and potential production bottlenecks.

2. **Product-Wise Analysis:** Comparing downtime across products and flavours helps identify which production categories may require further investigation.

3. **Root-Cause Analysis:** Categorising downtime reasons helps distinguish recurring operational issues and identify opportunities for corrective action.

4. **Operator Performance:** Analysing operator-related downtime can help identify training needs and opportunities to improve standard operating procedures.

5. **Production Efficiency:** Comparing production volumes and downtime indicators helps evaluate operational performance and identify areas for improvement.

6. **Interactive Analysis:** Dashboard filters allow users to explore performance by date, product, flavour, operator, and downtime category, supporting more detailed analysis.

*Note: These insights describe the analytical areas supported by the dashboard. Specific findings and numerical conclusions should be confirmed using the actual dashboard data.*

## Business Recommendations

- Investigate recurring downtime reasons and prioritise corrective actions.
- Monitor production KPIs regularly to identify performance deviations.
- Review product-specific downtime patterns to improve production planning.
- Provide targeted operator training where analysis identifies a need.
- Use historical downtime trends to support preventive maintenance planning.

## Project Objective

The primary objective is to transform production data into actionable insights through an interactive Power BI dashboard, enabling better operational monitoring, improved productivity, and more informed business decisions.

## Conclusion

The Line Productivity & Downtime Analysis Dashboard demonstrates how business intelligence and data analytics can support manufacturing operations. By monitoring production indicators and analysing downtime patterns, organisations can identify potential inefficiencies and develop data-driven strategies for continuous improvement.
